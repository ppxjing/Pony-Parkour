星星计分 UI

位置：游戏画面左上角，格式为 ⭐ 已收集数量/本关总数。
实现：Assets/_Project/Scripts/UI/KitchenRaceManager.cs。
运行时生成在 Race HUD/Star Counter/Star Count Text，无需在每个场景单独配置。

规则：
- 玩家实际接触当前星星时加 1，同一颗只计一次；AI 不会增加玩家计数。
- 死亡和复活保留本次关卡已收集数量。
- 切换关卡、重新加载关卡或重新 Play 时从 0 开始，各关分别计算。
- 当前比赛为两圈；第一圈起点不生成星星，因此总数 = 路径点数量 × 2 - 1。
- 当前验证总数：Beach 31，Kitchen_Adventure 25，Bedroom 39。
- 修改关卡路线后总数会在开始运行时重新计算，不需要手工修改分母。

验收：
1. Play 后左上角显示 ⭐ 0/本关总数。
2. 走到星星旁边但未碰到时数字不变；碰到后只加 1，星星继续播放上升旋转渐隐动画。
3. 死亡复活后数字保持；暂停不会增加数量。
4. 完成 Beach 两圈时显示 ⭐ 31/31。
5. 从 Beach 切换到 Kitchen_Adventure 显示 ⭐ 0/25，进入 Bedroom 显示 ⭐ 0/39。
6. 重玩同一关从 0 开始。

验证记录：Unity 编辑器编译无错误；Play 模式受控接触测试确认 Beach 0→1、不重复计数、死亡复活保留、两圈 31/31；实际场景加载确认 Kitchen_Adventure、Bedroom 独立从 0 开始并可加 1。已截图检查左上角布局。
